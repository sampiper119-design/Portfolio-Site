Context: Inspired by a brand collateral assignment completed for school, the Botanic Bloom Bistro project expanded into a comprehensive front-end web experience and physical brand identity system for an original, conceptual restaurant. The main goal was to explore how authentic a concept restaurant site could feel by connecting a digital user experience with physical brand collateral.

On the web development side, the project features a fully responsive layout complete with an animated hamburger navigation menu, a reservation form using datetime-local and numerical inputs, and an interactive tab-based menu system programmed for instant state resets and main/sub-category switching.

Simultaneously, the brand identity system entails a custom-designed logo, a corporate letterhead, a business card, and a tri-fold print take-home menu that integrates clear visual hierarchy with calls to action– including QR code reservation links. Across both print and digital mediums, the project maintains strict visual continuity by pairing an organic colour palette and floral motifs with readable typographic design.

Goal: To create a cohesive, end-to-end brand identity system for an original, restaurant concept, bridging a realistic front-end digital experience– complete with simulated interactive elements– with physical brand collateral in the form of a business card, corporate letterhead, and a tri-fold layout, print take-home menu.

Timeline: Aug 2025, July 2026

Tools: Notepad++ Visual Studio Code Adobe Illustrator

Process & Iterations:

The web development portion of this project did not take any real concept planning beforehand. I simply had an idea, looked at inspiration, and dove headfirst into programming. Additionally, ChatGPT was utilized to handle mass content generation of realistic menu items, descriptions, and pricing across both the web platform and print collateral, in order to keep the main focus on building interactive UI tools, fluid responsiveness, and state management.

Step 1

Began by diving straight into code to build the core digital experience. Programming a fully responsive website layout, navigation controls, reservation forms, and dynamic UI components.

Step 2

Programmed interactive tab-based state management for the digital menu system while utilizing AI assistants to generate realistic menu items, descriptions, pricing.

Step 3

Developed a comprehensive graphic identity framework– establishing a colour palette, clean typographic rules, and custom logo marks– and translated those visual rules across physical print deliverables, including a business card, corporate letterhead, and a tri-fold take-home menu.

The Challenges:

  • Bridging Digital and Physical Design Systems: Translating digital web layouts, colour palettes, and typographic hierarchies seamlessly into physical print collateral without losing visual identity or brand consistency.
  • State Management in Dynamic Menus: Programming a tab-based menu interface that handles instant category and sub-category switching, while maintaining clean state resets across sections.
  • Scaling High-Volume Content: Using AI assistants to mass-populate both the digital and physical menu with realistic items, descriptions, prices, and images.

Key Features & Highlights:

  • End-to-End Restaurant Brand System: Created an interactive, front-end web application, along with a cohesive set of physical collateral.
  • Interactive Web Application: Built a complete front-end experience that entails a fully responsive layout, a mobile hamburger navigation menu, and reservation forms that utilize specialized input types such as datetime-local.
  • Tabbed Menu State Management: Features dynamic category filtering that allows users to seamlessly switch between menu sections (drinks, appetizers, entrees, desserts) with clear visual tags like "Popular" and "Seasonal".
  • Physical Print Collateral: Designed a tri-fold take-home menu, a corporate letterhead, and a business card that collectively incorporates floral motifs, elegant typography, and a reservation QR code CTA.
  • AI Data Generation: Utilized AI to scale realistic restaurant menu content, keeping the main focus on front-end coding, UI interactions, and visual design rules.
